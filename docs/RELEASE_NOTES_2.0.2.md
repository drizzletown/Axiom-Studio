# Axiom Studio 2.0.2 · 单主线界面更新

**产品体验：** 首页改为一条五阶段流程（目标、规则、构造、验证、交付）。每个阶段只有一个主要工作区；旧版多套卡片与工程记录默认隐藏并保留在专业工具中。白底黑字，帮助只用五句话描述流程。

**保持原语义：** 复用既有项目创建、规格模型检查、人工验收场景、AI 构造工单、C++ 增量验证与证据 Gate；未改变任何验证器或准入策略。后端仍独立决定验证状态，UI 不授予发布权限。没有接通的步骤不能伪装成已经完成。

**验收边界：** 接口/结构测试及浏览器本地桥接下的项目创建、步骤切换和帮助操作通过；浏览器直接访问本地环回地址受环境限制，Windows 原生用户验收和完整历史联合回归仍未完成。
