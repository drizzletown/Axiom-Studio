# Axiom Studio V0.7：生产力工作台

**冻结定位：** Axiom Studio 不重复制造已有的软件开发工具，而是把 AI、程序构造、行为规格、独立验证、可信证据与持续演化组织为一个完整的软件工程体系。源码编辑继续复用 VS Code。

## 这次交付什么

- **创建项目：** 选择三种可运行模板；自动在 `workspace/projects/<slug>` 下复制独立工程，建立真实的 Axiom Workflow。不会覆盖已有工程；创建时不执行 C++ / 调用外部 AI。
- **生产任务中心：** 按真实项目、证据和版本状态计算下一步操作，直接进入规格验证、人工冻结契约、方案构造或演化；不存在一键绕过 Gate。
- **可交接生产包：** 逐项导出实际规格、实现、测试、Manifest、当前流程状态、构造任务（如已人工冻结）和 SHA-256 完整性清单。导出的 ZIP **未签名、非可信认证、非生产发布许可**；接收方必须独立重新验证。
- **自动化接口：** 本地 token 保护的 HTTP API + 无头 CLI。支持脚本启动项目、验证模型、查看待办、生成契约草稿、冻结经人工审核的映射、导出交接包。

## 启动

Windows（先安装 Python 3.10+）：

```powershell
python -m pip install -r requirements.txt
python run_studio.py
```

或运行 `启动AxiomStudio.bat`。

启动后，在软件构造项目全景的顶部打开 **新建可运行项目**。也可以使用：

```bash
python scripts/production_cli.py templates
python scripts/production_cli.py init --template model-toggle --slug my-switch --name "My switch" --goal "保证状态转换符合给定性质" --verify-model
python scripts/production_cli.py queue
# 从前一步返回的 project_id 填入下列命令
python scripts/production_cli.py draft <project_id>
# 人工核实每条 REQ 的陈述，保存为 JSON 数组
python scripts/production_cli.py freeze <project_id> --file reviewed_requirements.json
python scripts/production_cli.py export <project_id> --output handoff.zip
```

### 导入已有 VS Code / C++ 工程

无需改造或重写编辑器：将现有的 Axiom 规格与 `ax-cpp-project/0.1` 工程清单置于同一项目树，明确指定源目录；工具只复制受清单约束的源码和测试，原项目保持不变：

```bash
python scripts/production_cli.py import --source /path/to/existing/project --slug imported-app --name "Imported app" --goal "验证已有实现的业务不变量" --spec ledger.ax --manifest project.json
```

导入后用 VS Code 修改 `workspace/projects/imported-app/` 中的副本；原始工程不被覆盖。目录符号链接、越界路径、重复工作区、非白名单扩展名和过大文件都被拒绝。尚不支持没有 Axiom 规格和兼容清单的任意现有仓库“一键证明正确”。

## 重要边界

1. `verify-model` 只完成有限状态模型检查，不能当作真实 C++ 的形式化证明。
2. 生产契约中自然语言需求与性质的映射要求人工核实，候选 AI 不能自行修改性质、测试或 Gate。
3. C++ 编译与运行必须从原有工作流入口分别确认可信本地源码；V0.7 不提供不可信 C++ 的生产级执行隔离。
4. 工作包包含真实源代码与测试文件，因此导出前应确认没有敏感业务信息；运行证据数据库、密钥和令牌不会加入 ZIP。
5. 产品仍属于单机、测试级软件构造工作台，而非多租户生产服务或软件正式发布系统。

## 运行验收

```bash
python -m pytest studio/tests/test_launchpad.py -q
```

新增测试覆盖：模板复制/源工程独立、路径注入拒绝、真实模型检查、契约与任务摘要、版本失效、导出完整性、token 验证、HTTP 下载与不执行 C++ 的默认路径。
