# Axiom Studio 2.0.0 里程碑版本

2026-10-29 · 本地可信软件生产工具 · 源码发行版

## 冻结定位

Axiom Studio 不重复制造已有的软件开发工具，而是把 AI、程序构造、行为规格、独立验证、可信证据与持续演化组织为一个完整的软件工程体系。代码编辑借助 VS Code 等成熟工具。

## 2.0 新增

- **可信交付验证中心**：从项目及冻结验收契约创建独立验证批次，绑定规格、C++ 清单、源文件、测试文件和项目状态摘要。
- **跨版本影响分析**：比较上一次通过的验证批次，列出实际变更文件及受到影响的测试；无论变化范围如何，每次都执行全局规格与工程 Gate。
- **真正的增量 C++ 验证**：复用原 Axiom P2h 引擎已有的依赖、编译器与工具链绑定缓存。引擎只复用合格的非集成测试证据，集成测试始终重新执行；Studio 不自行裁定是否可复用。
- **人机责任分界**：运行 C++ 必须再次明确授权；未经授权或输入漂移，验证不会启动或不会获得通过结论。
- **可追溯验收**：完整记录实际命令输出摘要、返回码、结果、审核事件及 SHA-256 哈希链，导出可交接的 JSON 验证报告。
- **统一 API 和 CLI**：新增 `/api/milestone20/*` 和 `scripts/milestone20_cli.py`，可从现有工作台操作。

## 可用性

打开默认工作台，在“可信交付验证中心”选择已经完成规格模型检查并冻结验收契约的 C++ 项目。

1. 点击“创建验证批次”；系统显示受影响文件与测试。
2. 只有审阅并信任本地 C++ 代码时才点击“确认代码可信并开始实际验证”。
3. 查看四项独立验证结果与通过/阻断原因。
4. 导出验证报告；需求或代码变化后，创建新的验证批次。

命令行：

```bash
python scripts/milestone20_cli.py list
python scripts/milestone20_cli.py plan <project-id>
python scripts/milestone20_cli.py show <batch-id>
python scripts/milestone20_cli.py verify <batch-id> --trust-reviewed-native-code
python scripts/milestone20_cli.py handoff <batch-id> --output report.json
```

### 保证边界

- 当前是**可信本地代码运行**，不是防御恶意原生代码的生产级沙箱；C++ 运行不得在不受信任工程上执行。
- 本地 SHA-256 事件链检测意外篡改，但不是独立数字签名或远程不可抵赖审计。
- 有限模型验证是有界结论，C++ 测试级通过不等同于一般性形式化证明，不授予生产发布许可。
- AI 建议仅为候选；审查 Agent 的建议不是独立验证。
- 已知的较大历史联合测试超时仍需后续处理；本次只报告确实执行的指定回归。
