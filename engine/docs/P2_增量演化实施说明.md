# Axiom P2（第一批）增量演化实施说明

**基线**：AX-BL-0.2 / AX-HLD-1.0；**版本**：0.3.0；**时间**：2026-10-25。

## 已完成的可执行范围

1. P0 与 P1 的现有流程保留；P2 新增类型化语义依赖图，描述类型、状态字段、初始条件、动作、观察及性质的 may-affect 依赖。
2. Canonical Behavior Core = `(schema_version, semantics_version, model, types, state, init, actions, observe)`；核心摘要相同是模型级证据跨版本复用的必要条件。
3. 证据复用进一步要求同名性质表达式摘要相同、验证义务 ID 相同、有限穷举成功、当前工具校验摘要一致且工件内容可校验。
4. 新增性质仅使该性质的新验证义务成为 Missing；删除或修改性质不影响其他同一核心下未改变的性质证据；修改动作、类型、状态或观察导致行为内核摘要改变，保守失效所有旧验证义务。
5. P1 的 `cpp-gate` 独立，不接受仅由模型级 `evolve-gate` 给出的证明级别替代。
6. P1 CLI 未提供隔离沙箱，故要求显式 `--trusted-local`；进一步增加进程组超时清理、输出文件限额、无符号链接的 .cpp 候选限制。

## 验证与结果边界

- 已执行完整回归：52 项通过；其中新增 P2 12 项、P1 安全边界 4 项。
- 端到端脚本在新临时工作区记录旧模型成功、添加新性质之前阻断、补证后通过、动作改变之后全部旧证据失效。
- P2 的 Approved 目标只叫 `model-incremental-prototype`；不等同真实 C++ 已经满足规格。
- 依赖分析目前是保守启发式解释工具；批准复用必须额外满足完整行为核心等值，不能以图的有限可达关系代替正确性证明。
- 当前证据库仍由本地同一权限程序维护，不抵抗恶意本机用户或能够篡改索引和程序的代理。

## 后续必要工作

P1 工程硬化尚未完成安全隔离：需要将 C++ 编译和执行部署到受控低权限工作进程或容器/VM 中，隔离网络、文件系统、系统调用、进程数以及写入证据库的权限；独立可信服务只能接受来自验证器的工件及结果。

P2 后续需实现显式模块契约及组合式推理、对 C++ 绑定/代码/编译环境的影响传播、正式证据生命周期状态机、基线对照实验和多轮修改的验证成本统计。当前不宣称已有跨行为变更的安全复用或规模化性能提升。
